# Ideas

Things worth doing that are not being done now. One file each, with a rationale. New ideas that
come up mid-story go here instead of expanding the story; they re-enter through BMAD's
correct-course workflow or the next create-story.

## Adding an idea

Add a new file `docs/ideas/<yyyy-mm-dd>-<slug>.md` (today's date, a short kebab-case slug) that
starts with a `# Title` line. Do not edit this page and do not append to another idea's file:
this list is built from the folder when the site is built, so two pull requests that each add an
idea never touch the same lines. `IdeasIndexTest` checks the file names and titles.
