## Not confirmed

What the reader looked for and could not settle from the code; each item is an open question for the epic that needs it.

- **`Weapon`-level `damageRoll`**: `Weapon.java` has no `damageRoll` override at this tag (grep); the chain is `KindOfWeapon.damageRoll` -> `MeleeWeapon.damageRoll` (augment + excess STR). Missile weapons and `RingOfForce.damageRoll` were not read.
- **`Hero.stealth()`**: no override exists in `Hero.java` (grep for `stealth` finds nothing), so hero stealth is `Char.stealth()` = Obfuscation only. Whether other systems (e.g. Cloak of Shadows) feed detection through `invisible` rather than `stealth` was not traced.
- **`INVESTIGATING` state** exists (Mob.java:114, 1322-1345) but the comment says it is used only by vault mobs (`VaultMob.java`), which I did not read.
- **Sewer boss respawns**: `SewerBossLevel extends SewerLevel extends RegularLevel` (SewerBossLevel.java:54, SewerLevel.java:63), so `RegularLevel.mobLimit()` applies, but `SewerBossLevel.addRespawner()` returns null (SewerBossLevel.java:136-138) so no respawner runs there; the other four boss levels extend `Level` directly, whose `mobLimit()` is 0 (Level.java:686-688). I did not check whether `Dungeon.switchLevel` tolerates the null return.
- **Champion chance**: `rollForChampion` only applies with the CHAMPION_ENEMIES challenge (ChampionEnemy.java:109); the exact `Dungeon.mobsToChampion` reset behaviour beyond `= 1` at Dungeon.java:237 was not traced.
- **Alert icon duration**: `alerted` is consumed at the start of the next `Mob.act`, so the `!` is visible for one mob action; the exact frame timing of `EmoIcon` fade was not read.
- **`Mob.description()`** is `Messages.get(this, "desc")` (Mob.java:1040-1042); subclass overrides that might leak state text (e.g. Mimic, Statue) were not audited.
