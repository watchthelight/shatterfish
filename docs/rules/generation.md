## Not confirmed

What the reader looked for and could not settle from the code; each item is an open question for the epic that needs it.

- `WEP_T3.probs = WEP_T1.defaultProbs.clone()` (Generator.java:450) looks like a copy-paste slip (the T3 deck would start as `{2,0,2,2,2,2}`), but `fullReset()`/`reset(cat)` overwrite `probs` before any run draws (Generator.java:630, 645-655; Dungeon.java:252; restore also calls `fullReset` at Generator.java:926), so I could not find a path where it matters.
- The comment at RegularLevel.java:469 says held items do not affect levelgen, yet `ExoticCrystals.consumableExoticChance()` and `MimicTooth.mimicChanceMultiplier()` are read inside the main seeded scope (Generator.java:729-737; RegularLevel.java:408,430). Whether the extra `Random.Float()` calls shift subsequent draws depends on whether those branches are taken; not traced further.
- Whether quest sub-floor generation (branch 1) or revisiting a floor changes the category deck order relative to a straight descent was not traced; only that the deck is shared and persistent (Generator.java:620-622, 675-682).
- Exact item counts from special rooms that pull from `itemsToSpawn` via `findPrizeItem` (Level.java:801-827) were not enumerated; the guaranteed items can therefore sit in a special room rather than a floor heap.
- Shop stock beyond the fixed lines read (ShopRoom.java:222-343) was not enumerated.
