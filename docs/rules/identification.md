Every row was read from the pinned tag `v3.3.8` in bootstrap session 10 by a subagent following `.claude/agents/upstream-reader.md`; links open the cited lines at the tag. Tier 1 means the code confirms the rule; F means the code contradicts what an earlier document claimed and the row states what is true. Tests arrive with the epics that rely on each row (see [Codebase map](../codebase-map.md) for the discrepancies these rows settled).
