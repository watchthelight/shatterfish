# Roadmap

Epics as milestones on GitHub. This page mirrors them; bootstrap session 14 makes the mirror
exact (one milestone per epic, one issue per story) and the `sync-issues` skill keeps it so.
Each epic has a measurable "done when". The real epics and stories come from BMAD's
create-epics-and-stories workflow; this is the product owner's starting position from the
[bootstrap prompt](BOOTSTRAP-PROMPT.md), section 6.

| Epic | Milestone | Scope | Done when | Status |
|---|---|---|---|---|
| **E0 Bootstrap** | [E0](https://github.com/watchthelight/shatterfish/milestone/1) | Repository, upstream pinned, builds without Android SDK, module skeleton with the ArchUnit rule, docs system, CI, `CLAUDE.md`, project skills, BMAD planning artifacts through readiness check, issues mirrored | Section 11 checklist complete | in progress, [#1](https://github.com/watchthelight/shatterfish/issues/1) |
| **E1 Harness** | [E1](https://github.com/watchthelight/shatterfish/milestone/2) | Headless boot, `Observer`, `ActionExecutor`, seedable RNG, determinism, fairness tests, random-action agent | 1,000 seeded random-action Warrior runs complete in seconds; same seed twice is identical; all fairness tests pass | planned |
| **E2 Codex** | [E2](https://github.com/watchthelight/shatterfish/milestone/3) | Reflection dump by depth and challenges; properties parse; guide and lore pages; assets index; changelog dump; PD-vs-SPD vocabulary diff; generated docs; codebase map | `codex/<tag>/` regenerated by one Gradle task; CI fails on drift | planned |
| **E3 Rig** | [E3](https://github.com/watchthelight/shatterfish/milestone/4) | Parallel runner, seed sets, per-run results, SPRT, JSONL run logs, replay with hash verification, nightly Action, `docs/results/` | Random-agent baseline published; a deliberately-worse agent is rejected by SPRT | planned |
| **E4 Baseline brain** | [E4](https://github.com/watchthelight/shatterfish/milestone/5) | Scripted explore / fight-in-corridors / eat / descend; beliefs v1; `safeTest` | Kills Goo on a large majority of seeds; numbers in results | planned |
| **E5 Overlay v1** | [E5](https://github.com/watchthelight/shatterfish/milestone/6) | `EmbeddedDriver`, launcher, panel, pause / resume / step / run N / speed / take over, path highlight, native styling, run logging including human actions | The human watches a full sewers run and takes over mid-fight without desync | planned |
| **E6 Tactical search** | [E6](https://github.com/watchthelight/shatterfish/milestone/7) | Abstract model or redetermined rollouts; expectimax 2 to 4 turns when enemies are visible; hand-tuned eval from Codex tables and `Char.hit` | SPRT-significant improvement over E4 | planned |
| **E7 Strategy and lore** | [E7](https://github.com/watchthelight/shatterfish/milestone/8) | Item-ID logic, upgrade allocation, per-boss and per-class playbooks; lore pipeline with provenance and verification tiers | Measured win rate on default settings; every heuristic links to a lore entry with a tier | planned |
| **E8 Overlay v2** | [E8](https://github.com/watchthelight/shatterfish/milestone/9) | Explain panel, pause-on conditions, replay scrubber, beliefs view, hotkeys | Feature-complete per bootstrap prompt section 5 | planned |
| **E9 Learned eval** (optional) | [E9](https://github.com/watchthelight/shatterfish/milestone/10) | Value function trained on oracle hindsight labels, run on Observations only | Beats the hand-tuned eval under SPRT | optional |
