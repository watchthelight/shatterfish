- Round 1 named Ifritdiezel as a seedfinder successor; verified, but it is pinned at SPD 2.5.4 (2024-10) with no commits since, so it is not a current-version successor. The current-version line is Elektrochecker/shpd-seed-finder + shpd-toolkit (3.3.8, 2026-05) and, outside Java, akhial/shpd-seed-seeker (2026-09).
- "4.0.0-beta published 2026-08-15" (round 1) is correct as a release, but the tag carries no 4.0 source (identical commit to v3.3.8). Reading "prerelease tag" as "4.0 code is public" would be wrong.
- Evan's July 28 post projected a ~2-week beta; as of 2026-09-03 the beta is at BETA-4 (updated Sept 2) with no stable release, so 4.0.0 stable timing is open.
