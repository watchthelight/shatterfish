## Contradictions
- Release dates: the first WebFetch summary of github.com/TNG/ArchUnit/releases rendered 1.5.0 as "August 4, 2024" and 1.4.x as 2024; the GitHub API (authoritative `published_at`) gives 1.5.0 = 2026-08-04, 1.4.2 = 2026-04-18, 1.4.1 = 2025-05-07, 1.4.0 = 2025-02-10. The API dates are used above; the HTML summary was a summariser error.
- Maven Central: legacy search.maven.org reports latestVersion 1.4.1 (2025-05-07) and does not list 1.4.2/1.5.0, whereas GitHub releases and the archunit.org guide show 1.5.0. Most likely the legacy Solr index is stale (Sonatype migrated search to central.sonatype.com); treat 1.5.0-on-Central as single-sourced (TNG) until verified.
- Performance: issue #1160 (open, 87 s for 120 classes, 2023) vs. Loiane 2026 ("thousands of classes in seconds"). Plausible reconciliation: #1160's timings are dominated by classpath dependency resolution / JAR scanning rather than the project's own classes, which the `resolveMissingDependenciesFromClassPath` and `maxIterations*` knobs address; not confirmed from the issue thread this run.
