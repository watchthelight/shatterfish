## 3. SPRT as Fishtest uses it, adapted to win rate and depth

**Question.** Which sequential test should the rig use for win rate, which for depth while win rate is near zero, and what bounds and sample sizes follow?

**What Fishtest actually runs.** Fishtest does not run a textbook Wald SPRT but a Generalized SPRT: nuisance parameters are replaced by maximum-likelihood estimates, and the log-likelihood ratio is approximated as LLR = (1/2)(phi1 - phi0)(2 phi_hat - phi0 - phi1) / V(phi_hat), where phi_hat is the unconstrained estimate of the quantity of interest and V its variance estimate; the test stops when LLR leaves [ln(beta/(1-alpha)), ln((1-beta)/alpha)] [54, 53, 55]. The unit of play is a game pair with reversed colours scored on five outcomes (0, 1/4, 1/2, 3/4, 1), which captures the correlation inside a pair and saves testing resources over independent games [54, 53]. Bounds are stated in *normalized Elo*, e_n = (800/ln 10) x t_n with t_n = (mu - 1/2)/sigma_pg, chosen so that the expected duration depends only on the bounds and not on the draw rate or book [55, 57]. The live code (`sprt.py`, `LLRcalc.py`) implements exactly this: sqrt(2) scaling for pentanomial results, zero counts regularized to 1e-3 so the variance is never zero, and the LLR clamped against overshoot [56, 57]; fastchess ships an independent implementation of the same construction [60]. The expected worst-case duration at alpha = beta = 0.05 is D/(e_n,1 - e_n,0)^2 with D about 1.05 million games, which is why Fishtest's tests need tens of thousands of games for one or two normalized Elo [55]. Fishtest's current default bounds are shown as an image on the wiki and could not be quoted as text; historically STC and LTC used different bound pairs and were tightened when outcomes became less informative [59, 58].

**Win rate as a Bernoulli SPRT.** With increments ln(p1/p0) per win and ln((1-p1)/(1-p0)) per loss and bounds +/- ln 19, Wald's approximation for p0 = 0.05 versus p1 = 0.07 gives about 780 runs under H0 and 700 under H1 for a one-sample test against a known baseline [61, 62]; the lead's Monte Carlo (4,000 trials per arm) reproduced 808 and 727 with error rates of 4.6% and 4.8%, and Van den Bergh's Brownian formula gives about 750 at the endpoints and 1,220 at the midpoint [63, 55]. Two-sample comparisons roughly double the variance, so budget two to four times that. Near zero the test degrades: the loss increment vanishes while the win increment stays large, so a few lucky wins can end a test and overshoot is no longer negligible [61]; Fischer and Ramdas show Wald's approximate thresholds do not guarantee the nominal errors when beta > 0 and propose "sequential boosting" as a fix, whereas Fishtest simply clamps [64, 56]. A fixed-horizon test peeked at repeatedly inflates false positives to roughly a quarter, which is the argument for any pre-registered sequential rule [67].

**Depth and other per-run metrics.** The GSPRT approximation is metric-agnostic: for depth reached, phi is the mean, phi_hat the sample mean, V = s^2/N, and the test is a sequential t-test in the same twenty lines [54]. With paired seeds, the statistic is the per-seed difference d_i = depth_A - depth_B, whose variance is lower than the sum of the two arms whenever outcomes on a seed are positively correlated; this is the direct analogue of Fishtest's pentomial pairing [54]. Under H1 the expected runs are about 2.65 x 2 sigma^2 / (phi1 - phi0)^2, so a 0.3-floor improvement with a paired-difference standard deviation of 2.5 needs on the order of 370 seed pairs, against thousands of runs for the same evidence from win rate while p is near zero (illustrative arithmetic; the standard deviations must be measured) [54, 55]. Anytime-valid alternatives exist for when the effect size is unknown or several metrics are watched at once: mixture SPRT (deployed in commercial A/B testing) and e-processes, which allow stopping at any time and reject at 1/alpha [66, 65]; an anytime-valid sequential-rank test appeared in 2025 but no off-the-shelf anytime-valid Mann-Whitney for heavily tied ordinal data was found [68]. A reference sequential t-test implementation exists in R [69]; no Java library was found, and porting `LLRcalc` is small.

**Verdict.** Port Fishtest's GSPRT (the approximation, regularization, and clamp) to the rig and run it on paired-seed differences of an ordinal or continuous metric (depth reached, later a survival score) as the gating test until win rate is well above zero; report win rate with the same machinery's confidence interval but do not gate on it. State hypotheses in standardized units so one bound pair gives one run budget across metrics, pre-register the bounds and record a hypothesis id per test, and adopt two stages (a small seed set, then the standard set) like STC/LTC. Note the overshoot tension in the ADR and keep the clamp, revisiting sequential boosting only if error rates measured in simulation drift.

**Confidence.** High on the GSPRT mathematics and the Fishtest implementation (primary notes and source read in full, second implementation agrees); high on the sample-size arithmetic (formula plus simulation plus a second formula); medium on the depth-metric numbers, which use placeholder standard deviations; low on Fishtest's current default bounds, which were not obtained as text.
