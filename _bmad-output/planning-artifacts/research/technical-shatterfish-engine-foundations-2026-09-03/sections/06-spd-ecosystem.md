## 6. The Shattered Pixel Dungeon ecosystem

**Question.** What already exists around SPD (bots, RL, seed tools, headless and fork precedent), how does upstream's cadence affect a pinned fork, and where does reliable mechanics lore live?

**Upstream.** The repository has about 6,500 stars and 1,600 forks, two named contributors, ten open issues, GPL-3.0, and a README that states "this repository does not accept pull requests!" while offering the code for reuse [70, 71]. Minor versions land every three to six months (v3.0.2 2025-03, v3.1.1 2025-06, v3.2.5 2025-09, v3.3.8 2026-03) [72]. The `4.0.0-beta` tag published 2026-08-15 points at the same commit as v3.3.8 and the release page says "there is no public source code for beta releases"; upstream master has had zero commits since the week of 2026-03-22 after 291 commits in the preceding 28 weeks [73, 74, 75]. Evan develops 4.0 privately and will drop roughly six months of work at once; its announced contents are a new dwarven-city quest with a stealth enemy AI "currently only used in the new quest", art, enchantments, a challenge overhaul, and bugfixes, with no statement of restructuring, and v3.3.8 already contains the quest's tester area [77, 78, 79]. Merge cost is therefore unmeasurable today and should be measured with one `compare` call when 4.0.0 stable appears.

**Seeds.** Custom seeds shipped in v1.3 (2022). Evan's definition is generation-only: "When the game generates the dungeon, a lot of purely random calculations are involved. If they're given a numerical 'seed', then these calculations always give the same result"; the post says nothing about combat rolls or identification either way, and also introduced multiple floors per depth [76]. Community tooling confirms the practical corollary: seeds are guaranteed only within a build, "likely, but not guaranteed" to match across patch versions [81, 92].

**Bots, RL, and headless precedent.** No working bot, TAS, RL agent, or gym environment for SPD or Pixel Dungeon exists: the only bot project is an abandoned university course fork with no results, and Gymnasium lists no Pixel Dungeon environment [84, 85]. The nearest precedent for driving the game's code without playing it is the seedfinder lineage: the original patched upstream source to run generation from a CLI and is archived; its successors are a full fork at v3.3.8 with an in-game seedfinder and a CLI line whose boot recipe keeps the LWJGL3 application with `setInitialVisible(false)`, patching a dozen game classes to expose generation results, rather than using the headless backend [80, 81, 82]. A Rust reimplementation of the generator reports 147 seeds per second per JVM process for the game's own generator across 19 floors, the only throughput figure found (self-reported, single source) [83]. SPD forks keep up with upstream either by wholesale git merge (Experienced PD, which stopped at 2.5.x) or never (Radish, pinned at 1.4.3); the most-starred non-Evan mods have 27 stars or fewer and are mostly inactive [86, 87, 88].

**Lore sources.** Two wikis exist: the Fandom wiki, which hosts vanilla Pixel Dungeon and Shattered pages on one site under prefixes and is the main vector for confusing the two games, and pixeldungeon.wiki, created 2025-06-28 to replace it, Shattered-focused, with 299 pages and Discord links [91, 89]. The new wiki carries formula-level mechanics that name code identifiers (`attackSkill`, `defenseSkill`) but cite no source file, so it is a useful hypothesis generator and never a citation [90]. Evan's blog remains the design-intent source; upstream links no Discord or subreddit, and 2026 posts direct discussion to Lemmy and the Steam forums [71].

**Verdict.** Shatterfish enters an empty field: nobody has driven SPD headlessly for play, and the closest tools patch the game to run generation inside an invisible window. Pin at v3.3.8, expect a single large upstream drop for 4.0 with content-heavy rather than structural changes, and measure the merge with one API call when it lands. Treat the seed as fixing generation only until the code says otherwise, and treat both wikis as tier-3 lore pending `path:line` citations.

**Confidence.** High on upstream facts (GitHub API and Evan's posts read directly); high on the absence of bots (two searches, two sources); medium on the seedfinder throughput figure (single, self-reported).
