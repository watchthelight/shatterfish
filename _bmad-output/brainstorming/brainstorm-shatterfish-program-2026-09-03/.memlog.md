- (technique by coach) First Principles: fairness and search
- (idea by coach) SEARCH: search sees Observation plus beliefs only; hidden state is sampled from beliefs (redetermination) before every rollout
- (idea by coach) SEARCH: belief model is a first-class fairness object: Beliefs.update(Observation) is a pure function with its own leak tests
- (idea by coach) SEARCH: tension resolved: brain cannot import game code and cannot reimplement rules, so the harness offers an engine-backed fair simulator that runs the real engine on redetermined reconstructions
- (idea by coach) SEARCH: reconstruction option A: build a Level and mobs from the Observation plus a belief sample (world builder)
- (idea by coach) SEARCH: reconstruction option B: snapshot the real save (Bundle) and scrub hidden information by re-sampling it; fair only if scrubbing is complete, so it needs differential tests
- (idea by coach) SEARCH: search leak test: replace the true hidden state with random alternates; decisions must be identical because search only sees beliefs
- (idea by coach) SEARCH: strategy fusion pitfall: averaging over determinizations pretends the hidden info will be known later; limit horizon or use information-set search
- (idea by coach) SEARCH: MVP for E6 is one-ply lookahead over Codex tactical tables (expected damage, hit chance by level difference, speeds); no simulation needed
